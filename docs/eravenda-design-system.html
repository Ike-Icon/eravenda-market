System Execution & Runtime Pipeline

Data flow between browser client, FastAPI backend routers, Jinja templates, and static assets.

Step 1: Request Initialization Browser

Client Requests HTTP Route

Browser requests page route (e.g., /services/professional or /admin/dashboard).

Step 2: API Routing & Validation FastAPI

FastAPI Backend Endpoint Processing

backend/app/routers/*.py processes request parameters using Pydantic schemas in backend/app/schemas.py.

Step 3: Layout Composition Jinja Engine

Jinja Template Hydration

Template inherits from frontend/templates/base.html, loading headers, footers, and domain layout modules.

Step 4: Style & Dynamic Hydration CSS / JS Engine

Runtime Asset Rendering & API Fetching

Tailwind CDN and custom.css render component styles; api.js executes standard apiFetch operations.

4-Tier Component Taxonomy

Layered breakdown from foundational tokens to full page compositions.

Tier 1

Foundations

  • Typography: Space Grotesk (Headings), Inter (Body)
  • Design Tokens: Brand Colors (50-900), Accents (400-600)
  • Layout Tokens: Radii (6px default), Breakpoints (480px to 1024px)
Tier 2

Shared Primitives

  • Controls: Button, IconButton, SegmentedControl, Select
  • Feedback: Badge, StatusPill, Alert, Modal, Drawer
  • Data Presentation: Money Formatter, DataTable, Skeleton Loader
Tier 3

Domain Components

Market Domain:
ProductCard, PriceBlock, CartLineItem, CheckoutSummary
Handyman Hub:
ProfessionalCard, BookingStepper, JobPhotoGrid, PayoutLedger
Tier 4

Page Compositions

  • Public: Home, Product Listing, Handyman Directory
  • Workspaces: Seller Workspace, Professional Dashboard
  • Oversight: Admin Financial & Verification Dashboard

File Ownership & Responsibility Matrix

Strict boundary map separating backend logic, frontend layout, and styling assets.

Architecture Layer File Path Strict Ownership Scope
Global Shell frontend/templates/base.html Root HTML wrapper, CSS tokens, Tailwind CDN, core script bindings.
Navigation Component frontend/templates/components/header.html Global branding header, search inputs, account links, mobile navigation drawer.
Legacy Token CSS frontend/css/style.css Legacy token definitions, structural button variants (.btn), reset rules.
Design Token Overrides frontend/static/css/custom.css Active token definitions, component overrides, focus ring defaults, status colors.
Client JavaScript API frontend/js/api.js apiFetch wrapper, standard headers, auth token parsing, global error interception.
Backend Service API backend/app/routers/*.py Business logic, payment calculations, verification rules, database query execution.
