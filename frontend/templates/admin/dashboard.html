Delivery fees

Each store in a buyer's cart gets its own delivery fee: a distance fee plus, if you switch it on, a weight charge. Changes apply to every new quote and order straight away. Orders already placed keep the fee they were charged. Pickup is always free.

Free delivery

A delivery inside the base city (the buyer and the store both there) is free when that store's order is above the amount below. An order of exactly that amount still pays. It replaces the whole fee, including any weight charge. Orders to or from other cities are not affected.

Distance fees (GHS)

Distance is worked out from the buyer's address and the seller's store location, not from GPS. Pick the base city, then set the fee for each band.

Weight charge

An extra charge on each store's order, based on the total weight of its items. Sellers enter each product's weight when they add or edit it. While this is off, weight is ignored.
